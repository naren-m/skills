# Sutra Writing

Write clear, concise text, designs, and code without losing the conditions, evidence, or failure handling needed to make them correct.

## What is a sutra?

A sūtra preserves a large idea in a short rule or teaching. Its compact form helps people remember it, while commentary develops its meaning. Brevity matters alongside clarity, useful meaning, little repetition, and correctness.

This skill applies that idea to writing and coding: keep the essential meaning, remove repetition, and make rules and limits explicit. For code, use the smallest complete implementation with clear errors and focused tests.

Read the [Sutra note in literature-notes](https://github.com/naren-m/literature-notes/blob/main/content/domains/humanities/sanskrit-literature/Sutra.md) for the background.
