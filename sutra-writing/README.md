# Sutra Writing

Write clear, concise text, designs, and code without losing the conditions, evidence, or failure handling needed to make them correct.

## What is a sutra?

A sūtra preserves a large idea in a short rule or teaching. Its compact form helps people remember it, while commentary develops its meaning. Brevity matters alongside clarity, useful meaning, little repetition, and correctness.

This skill applies that idea to writing and coding: keep the essential meaning, remove repetition, and make rules and limits explicit. For code, use the smallest complete implementation with clear errors and focused tests.

Read the [Sutra note in literature-notes](https://github.com/naren-m/literature-notes/blob/main/content/domains/humanities/sanskrit-literature/Sutra.md) for the background.

## Sanskrit definition

The [earlier version of the note](https://github.com/naren-m/literature-notes/blob/d70415036cf7772045d1fbe4f43146cfd7cb00a4/content/domains/humanities/sanskrit-literature/Sutra.md) preserves this definition, quoted as written:

> अल्पाक्षरमसंदिग्धं सारवद्विश्वतोमुखम् । अस्तो-भमनवद्यं च सूत्रं सूत्रविदो विदुः

Its terms describe the qualities of a sūtra:

| Term | Meaning |
| --- | --- |
| alpākṣaram | Use few letters or words. |
| asaṃdigdham | Be clear and unambiguous. |
| sāravat | Carry essential meaning. |
| viśvatomukham | Address all aspects; the note describes this as universal applicability. |
| astobham | Avoid unnecessary repetition or filler. |
| anavadyam | Be free from faults. |

For this skill, these are practical checks: use few words, preserve the substance, state scope and conditions, remove repetition, and verify correctness.
